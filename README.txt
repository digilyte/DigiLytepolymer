DIGILYTE POLYMER WEBSITE
========================
Files:
- index.html (Home)
- products.html (catalogue)
- about.html
- contact.html
- style.css
- script.js

HOW TO PUBLISH:
1. Open your GitHub repository: digilyte-polymer
2. Upload/replace all these files in the repository root.
3. Commit changes.
4. GitHub Pages should update automatically at:
   https://digilyte.github.io/digilyte-polymer/

NOTES:
- Product names are based on the DigiLyte Polymer catalogue previously shared.
- Prices are not shown because they may change; contact the business for current rates.
- The enquiry links open WhatsApp or the visitor's email app. No backend form/database is included.
- CSS illustrations are placeholders. Send clear product photos/logo to replace them with actual imagery.
